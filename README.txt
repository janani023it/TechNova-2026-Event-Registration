TECHNOVA 2026 - EVENT REGISTRATION WEBSITE

Files:
1. index.html - main website
2. style.css - responsive design and styling
3. script.js - form validation and localStorage data management

How to run:
- Keep all 3 files in the same folder.
- Double-click index.html, or open it in a browser.
- Test navigation, form validation, registration success, and records.

Activity mapping:
- Event category: Technology Event
- Website sections: Home, Event Details, Schedule, Registration, Records, Contact
- Registration fields: Name, Register Number, Department, Year, Email, Mobile, Event
- Validation: required fields, email format, mobile format, incomplete submission prevention, success message
- Data management: browser localStorage demo
- AI assistance: layout/code ideas and JavaScript validation
- Responsive design: CSS media queries for mobile
